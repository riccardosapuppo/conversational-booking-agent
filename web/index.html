Where a model would go, and why there is only one such place

One file has an opinion about what an English sentence means. Everything after it — the flow, the catalogue, the diary — works on a Reading, which is plain data. So the whole of the agent’s behaviour can be tested without a model, and a model cannot reach past that line to change any of it.

The socket is the Reader protocol, and it is … wide: …. A model-backed reader is a class with that method, handed to the service when it starts. There is no second place to put one.

Nothing is connected to a model here, and this page will never ask you for a key — a demonstration that wants an account before it does anything is a demonstration nobody runs. This clinic does not exist and nothing here is kept between two runs.
